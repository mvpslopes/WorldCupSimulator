# 🏆 Simulador de Copas do Mundo

Um simulador realista da Copa do Mundo com 32 seleções baseadas no ranking FIFA, desenvolvido com React, Tailwind CSS e Framer Motion.

## ✨ Funcionalidades

- **Simulação Completa**: 32 seleções reais com ratings baseados no ranking FIFA
- **Fase de Grupos**: 8 grupos (A-H) com 4 seleções cada
- **Fases Eliminatórias**: Oitavas, Quartas, Semifinais e Final
- **Histórico Persistente**: Todas as Copas simuladas são salvas no localStorage
- **Estatísticas**: Ranking de títulos e gráficos de barras
- **Animações**: Transições suaves com Framer Motion
- **Tela de Campeão**: Celebração com confete e troféu animado

## 🚀 Como usar

1. Instale as dependências:
```bash
npm install
```

2. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

3. Acesse no navegador:
```
http://localhost:5173
```

## 📦 Tecnologias

- React 18
- Vite
- Tailwind CSS
- Framer Motion
- Recharts

## 🎮 Como funciona

1. Clique em "Avançar Tempo" para simular uma nova Copa do Mundo
2. Assista a simulação completa desde a fase de grupos até a final
3. Veja o histórico de todas as Copas simuladas
4. Acompanhe as estatísticas de títulos por seleção

## 🗑️ Resetar dados

Use o botão "Reiniciar Histórico" na tela inicial para limpar todos os dados salvos.
